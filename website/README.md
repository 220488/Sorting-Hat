# Sorting Hat — project website

Next.js introduction page for the Terminal-Bench 2.1 harness router, styled after the team poster.

## Run locally

```bash
cd website
npm install
npm run dev   # http://localhost:3456
```

## Deploy on Vercel

Import this repo in Vercel and set **Root Directory** to `website`. The framework (Next.js) and build command are detected automatically.

## Where to edit

- `app/page.tsx` — all page text
- `app/globals.css` — colours, fonts, layout
- `public/img/` — background, charts and logos
